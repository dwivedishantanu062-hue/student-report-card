Student Report Card – Java

A beginner-friendly Java console project that calculates a student's total marks, percentage, grade, and pass/fail result.

Features

- Takes student name as input
- Accepts marks in Mathematics, Hindi, and English
- Validates marks
- Calculates total marks and percentage
- Assigns a grade based on percentage
- Determines pass or fail

Technologies Used

- Java
- Scanner for user input
- Conditional statements ("if-else")

How to Run

1. Install Java JDK.
2. Download "studentgradecalculator.java".
3. Open the file in VS Code.
4. Run the program.

What I Learned

- Java variables and data types
- User input with Scanner
- Conditional statements
- Basic validation and calculations
